# ViedmaTech - Agencia de Desarrollo de Software

Trabajo Final Integrador para el **Taller de Desarrollo Web** (Viedma Digital).

## Descripción del Proyecto
Sitio web multipágina responsivo con estética Dark Tech para una agencia de desarrollo web, aplicaciones móviles y consultoría IT.

## Estructura del Sitio (6 Vistas)
* **Inicio (`index.html`):** Hero section y resúmenes de servicios, proyectos y empresa.
* **El Equipo (`equipo.html`):** Misión, visión, valores y fichas de los integrantes.
* **Servicios (`servicios.html`):** Detalle de las prestaciones tecnológicas en grilla responsiva.
* **Trabajos (`trabajos.html`):** Galería de 6 proyectos con filtro dinámico por categoría en JavaScript.
* **Presupuesto (`presupuesto.html`):** Calculadora interactiva de cotizaciones en tiempo real.
* **Contacto (`contacto.html`):** Información de ubicación y formulario con validación en vivo.

## Tecnologías Utilizadas
* HTML5 Semántico
* CSS3 (Flexbox, CSS Grid y diseño responsivo)
* JavaScript (ES6+ para interactividad y manipulación del DOM)
* Git & GitHub Pages
